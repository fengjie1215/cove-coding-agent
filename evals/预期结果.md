# 预期结果与验收标准

本文件在真实 API 评测之前制定。下列是**工程验收条件**，不是预言模型成绩。

1. `cases.json` 恰有 12 个唯一用例、三个夹具；每题原始实现不能通过对应公开和隐藏测试，参考实现均通过。
2. 模拟模型试运行六次全部完成正常验证、应用与隐藏检查；A 组不注入规则／记忆，B 组各注入一条。模拟结果仅证明运行器连通。
3. 修改验证配置、测试或其他非目标文件会在工具调用时被拒绝并记为越界尝试，自动验证前仍做最终 diff 复核；任务、规则、记忆和工作树只写入独立临时目录，不改变用户真实项目或 `~/.corecoder`。
4. 轮数与模型调用预算耗尽均标记为未完成，不计为正常完成；真实试运行若执行，生成六条结构化用例记录；正式批次若执行，生成 72 条记录，36 对可配对结果。报告必须列出全部失败与异常，不能删去不利样本。
5. 正式报告的主指标为「正常验证 + 正常应用 + 常规隐藏及记忆边界均通过」的比例；同时分列两类隐藏指标、模型、用例哈希、随机种子与重复次数。token 缺失标记为未知。

**不预设 B 组一定优于 A 组。** 若个性化无提升或变差，也如实报告，并分析规则冲突、记忆检索不相关、模型波动或任务设计偏差。真实 DeepSeek API 结果及简历可用数字须在实际运行和复核后填写。
